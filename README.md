# PayNoma

PayNoma is a rent and property management application under development, built to explore how web technologies can support rental management workflows.

## Technology Stack

### Backend
- Python
- Django
- Django REST Framework
- Simple JWT authentication
- PostgreSQL database driver

### Frontend
- React
- Vite
- React Router
- Axios
- Tailwind CSS
- Recharts
- Framer Motion
- Lucide React
